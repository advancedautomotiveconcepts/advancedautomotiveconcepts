## 2025-08-11 - Preventing Responsive CLS Layout Distortion and Pruning Google Font Weights
**Learning:** Adding explicit HTML `width` and `height` attributes on image tags prevents Cumulative Layout Shift (CLS) by allowing browsers to compute the aspect ratio before loading. However, in responsive layouts, if CSS does not declare `img { height: auto; }` globally alongside `max-width: 100%`, images will stretch or squash when they scale down. Furthermore, loading unused Google Font weights causes unnecessary download overhead; pruning them to exactly what is styled in CSS (e.g. Oswald 500/600, Inter 400, and JetBrains Mono 600) and adding a preconnect link with the `crossorigin` attribute to `https://fonts.gstatic.com` drastically reduces the DNS, TCP, and TLS handshake latency.
**Action:** Always declare `img { max-width: 100%; height: auto; display: block; }` globally when using HTML `width` and `height` attributes to prevent CLS, audit stylesheets to prune unused font weights, and preconnect to the actual font asset host (`fonts.gstatic.com`) with `crossorigin`.
