## 2026-07-29 - Google Fonts Pruning & Layout Shift Optimization
**Learning:** Overloading Google Fonts requests with extra weights (e.g. 400, 500, 600, 700 for multiple families) adds significant render-blocking payload and slows down visual load. Furthermore, declaring font-weight: 700 in CSS when only weight 600 of a font is loaded triggers browser synthetic (faux) bolding, which can look blurry and inconsistent.
**Action:** Audit CSS weights against HTML tags and Google Font families, requesting only the precise weights needed (Oswald: 500/600, Inter: 400, JetBrains Mono: 600). Map CSS declarations exactly to these loaded weights, and specify explicit width/height dimensions on layout images alongside `height: auto` global styles to completely avoid Cumulative Layout Shift (CLS).
