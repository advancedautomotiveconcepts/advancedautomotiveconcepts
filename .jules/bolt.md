## 2026-07-28 - Native HTML Image Optimizations for Bundler-less Static Websites
**Learning:** In a pure static website without a build pipeline, framework, or bundler (e.g. no Webpack, Vite, or Next.js), common image optimization techniques like automated responsive sizes or lazy-loading polyfills aren't available. To prevent Cumulative Layout Shift (CLS) and keep the page lightweight, we must manually specify explicit `width` and `height` attributes matching the actual asset dimensions on every `<img>` element, and leverage browser-native `loading="lazy"` for all below-the-fold assets.
**Action:** Identify and inspect actual dimensions of all image assets in the codebase using Python helper tools/PIL and apply explicit attributes directly in HTML files, reserving lazy-loading only for elements guaranteed to be below-the-fold to avoid delaying the first contentful paint (LCP).
